## Quality group — regression reproduction and specialized test matrices

Each obligation appears once, as its checklist row plus the rule text it carries.

- [ ] **A defect-reporting body's `Current Behavior` carries the reproduction facts — triggering steps or input, observed result, expected result, and environment.** A bug ticket also retains a test-first **bug-reproduction** case in Testing Strategy that demonstrates the reported defect against today's code before the fix: the regression test fails by exhibiting the exact wrong behavior (the dropped last row, the off-by-one), then passes after the fix, building on those `Current Behavior` facts.
- [ ] **A Testing Strategy enumerating a case matrix for a convention-governed surface carries the full matrix (or a named, justified narrowing) and its `governing conventions consulted:` line.** This applies only when the Testing Strategy enumerates an input-shape or case matrix for a surface (a parser, a config consumer, a best-effort input handler); a matrix-free Testing Strategy imposes nothing. When it does, and a repo-published convention already governs that surface's matrix, the issue either enumerates the **full convention matrix** or states the **narrowing explicitly with its justification** — a silently narrower list must never override the convention — and carries the one-line record `governing conventions consulted: <sources cited by path, or "none found; searched <the bounded list>">`. The search is **bounded to a named list** — `CLAUDE.md`, `CONTRIBUTING.md`, and testing guidance under the repo's configured internal-docs path — with the **consumer prompt extension** as the override point naming where that repo's conventions live; cite sources by path when found. The record is a **claim to verify, not an attestation to accept**: the Step 3.6 auditor re-runs the search and flags the line when a governing matrix sits at a path the line omits — **except on Step 3.6's degraded inline arm, where no auditor re-runs it and the record is attestation-only**, which that arm's mandatory `degraded` audit-summary marker already signals. **This matrix rule also fires on *introduction*, not only on narrowing:** an issue that introduces a **reader of input the repo does not itself produce** — historical records, user- or reporter-controlled text, an external structured format, agent- or human-mutable markdown — **enumerates the malformed / boundary shape matrix of the parts code reads in the Testing Strategy**, appropriate to the input's type, including **at least one production-realistic fixture** (a real captured record, not only a hand-built well-formed token); a narrower enumeration states its **justification**, and a **blanket testing-scope waiver** ("this artifact has no desk test") is **non-conforming** — a conforming one states what **inside the exempted artifact remains governed**. **Code reading text a model writes** (an agent's report, comment or record) reads by default only what the producer's contract marks for machine reading — a marker line, a fenced JSON block, a JSON file, or a heading, section or line shape the contract names as machine-read; a model reads the rest. A criterion, Approach or Architecture Alignment making code parse any other layout of that text (headings, section order, bullet shapes, or a count of them) is a **decision fork** — a model reads it; the producer emits the value as a machine-read field; or code parses the layout — routed like any new fork (`skills/spec/references/revision-delta.md` item 6); a run with no user never self-answers it and records it in `## 🚫 Blocked`. Skip the fork only when the user chose code parsing of that layout itself; a user decision naming an output or value the layout would supply is not that choice. The corresponding Testing Strategy residual case is the **new mutable-input-reader matrix** carrying its `governing conventions consulted:` record.
- [ ] **The draft's own unstated mechanism dependencies have their existence determined and are routed per Step 3.5's item 4 (`skills/spec/references/step-3-5-steelman.md`), an undetermined one recording not established.**
- [ ] **Specialized Testing Strategy residual cases are recorded when they add information beyond the criteria.** For a **guarantee-class change** (the deterministic backstop / hook / gate mechanisms on the Step 2 strength ladder), cover the path where the cooperative step was **skipped** — assert the mechanism fires when a human or agent *forgot* the cooperative step, and is idempotent where repeated enforcement is possible, not only when everyone cooperated. Also record **retry and idempotency behavior, and convention-governed matrices** the criteria do not already pin. Each surviving case names the residual risk it covers and the contract it protects.
