   Return-handling carve-out for an accepted final-byte pass: on `VERDICT: REVISE` its findings are adjudicated with a ledger like any round's and disclosed at the re-asked question, and the run then files on the user's explicit election — no mandatory revise-and-re-present cycle; on a verdict-less return the no-verdict machinery governs unchanged and the slot is refunded. Dispatch it with the generated instruction file exactly as any round, passing `--instructions-file`/`--instructions-draft-path` and quoting the auditor's `--instructions-object-id`/`--extra-dispatch-content` back on the return.
