   When the gate withholds the prompt, print a one-line reason naming the exact failed condition before the question — one of *declared dependencies present*, *blocked decisions present*, *cloud implement tier disabled or unconfigured*, *config unreadable (all read paths failed)*, or *tier state unestablished* (the degraded cell for `references/fallback-implement-offer-tier-read.md` in `references/degradation-routing.md`, taken when that file could not be loaded) — and on the disabled/unconfigured reason add that the alternative is to start `/prflow:implement` in a fresh session. A withheld offer is never silent, and the issue-created outcome (the URL and the sub-step 5a `PRFlow`-label result) is still reported in full. Select between *disabled/unconfigured* and *config unreadable* from what the fallback ladder observed, classified per the loaded `references/fallback-implement-offer-tier-read.md`; a resolver that answered cleanly at exit 0 needs no classification.
