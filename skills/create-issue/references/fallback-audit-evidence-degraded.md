## Degraded arms of an audit round

Each arm below is a terminal degraded state of one audit round. The round's own observable answer selects the arm; `references/step-3-6-audit-dispatch.md` names which. Every arm here is a disclosure, never a stop.

Carriage evidence absent or mismatched. A `record-return` classified `no-parseable-verdict` because the carriage evidence was absent or mismatched writes a named breadcrumb to stderr — `carriage-absent` when the auditor quoted no object ID, `carriage-mismatch` when it quoted one that disagrees with the recorded dispatch digest — while its stdout `classification=…` line and its exit code are unchanged. The remedy the breadcrumb names is to re-run `record-return` supplying `--carriage-object-id` with the object id of the draft the auditor actually audited (`git hash-object --no-filters <draft>`), so read the stderr breadcrumb before treating the round as genuinely unreadable.

Instruction-file generation failed. On a non-zero exit or empty output from the instruction-generation command, the round has no hashable instruction file. Dispatch first, then disclose — `record-degraded` attaches to a round that `record-dispatch` must already have opened. Dispatch on the earlier shape (naming the draft path and the renderer invocation directly, and omitting the `--instructions-file` pair), then record `record-degraded --round "<round>" --reason instructions-generation-failed`. Carry that `record-degraded` reason in the summary line beside the steering marker. Filing is not blocked; the state is disclosed.

Fallback ladder (no output, or markers missing/out of position). Auditor-side: the preamble instructs the auditor, on a renderer invocation that produces no output or output whose markers are out of position, to Read the template file at the absolute path the preamble names and follow its embedded instructions. Orchestrator-side (the `status-only` probe, the inline arm, the self-check, Step 2): assemble from the template file at the absolute path the run already holds, via the Read tool, per its documented slots. When the auditor can do neither, its return carries no parseable verdict and the state owner's no-verdict retry machinery governs the round, the retry hand-embedding the template-file text in full. When the template file is itself unreadable, the run takes a bounded one-round in-chat fallback in the `state-owner unavailable` shape — the orchestrator conducts the audit inline from the skill-retained policy prose, marks the audit summary line with a distinct `template-unreadable` marker, and proceeds to presentation with that disclosure. Every degraded arm is named in the in-chat audit summary line (skill-composed markers; the state owner's field set is untouched), but filing is never blocked on any arm.
