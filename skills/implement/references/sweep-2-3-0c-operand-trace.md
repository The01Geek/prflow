#### 2.3.0c Operand-trace sweep (mandatory whenever the diff adds or hardens a guard, predicate, validator, or coverage invariant in code, or ships agent-executed prose stating a policy)

2.3.0a/2.3.0b catch a rule or an enumerated value replicated across too few sites; 2.3.4 verifies a boundary the diff *reads* but explicitly carves out the diff's *own* code. This sweep closes the gap between them, and it has two authoritative triggers — run it when either fires:

- (a) Code trigger — the diff adds **or hardens** a guard, predicate, validator, or coverage invariant. A guard whose comparand comes from the diff's own code is covered by no other sweep: 2.3.4 carves out in-diff code, and 2.3.0a/2.3.0b watch peer sites and enumerated sets, not the operand a single guard reads.
- (b) Prose-policy trigger — the diff ships agent-executed prose stating a policy, wherever that prose lives. The policy's operand is a value the *agent* has to observe at run time — and a policy stated against an operand no step produces is inert.

Record. The sweep writes **one `--note`** when its trace fits the per-note byte budget (over budget, phase-2-implement.md §2.0.5's continuation route), one compact line per traced item: a guard comparand's line gives the comparand, its producer, and the guard's decided route on each producer-silence arm below that applies to it; a stated policy's line gives its operand, the producing instruction and the paths it covers, its other producers, and the source of each outcome's route, the producing step failing included — the issue, merge-base prose or mechanism, or an accepted limit — or, with none, why it has none and which of the deferral, prose removal, Blocked stop or merge-base exception below the run took. For any unestablished part of the producing instruction or of its other producers, a stated policy's line gives: `unestablished`; either the read or search of the selected paths' instructions that ran, as its command or path, and its result, or why no such lookup could run; and the Phase 3 review backstop. A line missing any of them — one naming neither a lookup that ran nor why none could run, such as one citing another record's statement that the producer is not established, included — is not the note line the sweep's completion below requires for that policy. The fuller work below stays in your context.

The operand trace. For every comparand the added **or hardened** guard/predicate/validator/coverage invariant reads (trigger a), and every operand a stated policy keys on (trigger b), work through these four fields:

- comparand or operand
- producer (file + line)
- producer behavior on every path the guard or policy now selects — can it fail or emit nothing, and what establishes a successful production?
- what OTHER inputs produce the same value?

The fourth field — the one asking what *else* produces the value — is the **load-bearing** one: it asks "what else exits 2?", since unrelated causes routinely share an exit code, so a guard reading "exit code 2 ⇒ no workpad" acts on a state it never observed. A comparand whose fourth field names another producer of the same value that the guard does not distinguish is a fail-open guard and a defect in **this** PR; so is a policy that does not distinguish another producer of its operand's value whose state the policy's route does not fit, unless the merge-base exception below applies. The policy's fix distinguishes that state; a state the run cannot distinguish counts as an unsourced outcome.

Every comparand enumerates the producer's silence and the guard's decided behavior — a direct read, a file-presence check, and a derived value alike. Enumerate the arms the producer can present that apply to that comparand: producer failure (a non-zero exit or a denial), unparseable or wrong-type output, a valid-falsy/empty value, and a missing key, file, or value — and state the guard's decided behavior on each. **Distinguish an established result from an unestablished observation:** a valid empty collection, `false`, `0`, an explicitly optional field, or a documented best-effort default keeps its intended meaning when the contract permits it — not every empty value or advisory failure blocks — while a required input that is absent, unreadable, malformed, or incomplete is unestablished evidence, never a clean value. A comparand whose trace leaves an applicable arm unenumerated is a defect in **this** PR: the guard's behavior on the unenumerated arm was never decided — so where the guard carries no fail-closed default it fails open on exactly the input the operand-trace exists to surface (a `.get('stats')` on non-object JSON that raises, an empty parse result that passes the guard green, a `[ -f "$f" ]` that never confirms the file it gates parses).

A gate whose contract requires established evidence to pass records, on its line, its non-passing route for evidence that is absent, unreadable, malformed, or incomplete — and passes only on evidence that meets the contract, never on the mere absence of an unsafe-state signal when the producer may emit nothing (no unsafe-state signal need exist for the gate to refuse).

Trigger (b) — the stated-policy contract. A policy's operand is the observable value the agent keys it on, and its producer is the final instruction performing the producing operation on each path the policy selects — a step name assuming the operation happens, or agent recall carried across a subagent dispatch, is not one. A read establishing that a selected path has no instructed producer identifies an inert guard and a defect in this PR — the promised routing can never fire, so the policy silently no-ops on exactly the input it was written to gate. An absent or unreadable source, a lookup that failed or did not run, or an unresolved producer identity leaves the producer unestablished: it discharges no trace and establishes no absence, and its note line records it so.

Take each outcome's route — the producing step failing and a distinguished other producer's state included — only from the issue's acceptance criteria or Desired Behavior (an accepted limit its criteria state included), or from prose or a mechanism at the merge base that the change keeps; write none of your own, and count an outcome whose source you cannot establish as having none. An unsourced outcome, or an undistinguished other producer, is not a defect in this PR when you establish both that the merge base's policy already leaves it so and that the diff edits neither the sentence keying the policy on that operand nor the route that state reaches. For any other unsourced outcome, defer each criterion requiring the policy through phase-2-implement.md §2.2.5's steps, its `--note` also naming the operand, the unrouted outcome and why it has no source, and keep none of the policy's added prose that no remaining criterion requires, text already written for a deferred criterion included; when no criterion would remain, take §2.2.5's empty-pushable-subset Blocked stop.

A stated policy places its obligation at the execution point it gates, carrying at most a cross-reference from any thematic section that also discusses it; prose that describes the hazard only in a thematic section, leaving the execution point it gates with no obligation, does not discharge this trigger.

The sweep is not done until every comparand has a completed four-field trace and its note line — with each comparand's applicable producer-silence arms enumerated and each arm's decided behavior stated, an established valid-empty/optional result distinguished from unestablished required evidence, and a gate's non-passing route recorded for missing evidence (trigger a) — and every stated policy has its four-field trace, its note line, and places that obligation at the execution point it gates (trigger b).
