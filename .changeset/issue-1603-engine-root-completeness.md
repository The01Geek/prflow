- **The review engine root must be established complete before it is executed on the file-read path.** The fix loop reaches `skills/review/SKILL.md` by an ordinary file read on three paths, and on each the acceptance predicate was that the read returned *something* — so a partially returned body was indistinguishable from a complete one and the run could execute a half-delivered merge gate with no stop label. The canonical statement in `skills/review-and-fix/references/loop-control.md` Step 1 now locates a candidate only once its returned body's completeness is established, reusing the existing marker-independent paged-read recovery (page forward on an `offset`/`limit` partial-view notice, judge the assembled whole); a read that cannot be completed, a gap in the page sequence, and an unclassifiable reader message each leave it unestablished. Step 4 routes the two failures apart: no body at all keeps the existing absent-engine fatal naming `/prflow:init`, while a body whose completeness could not be established stops at the new terminal `engine-root: incomplete`, which names the file, treats the body as unusable, repairs nothing, and — the case a truncation makes reachable — does not fall through to the next candidate, since that candidate is a different engine copy. `references/error-handling.md`, `references/shadow-review.md` and `skills/implement/phases/phase-3-fix-loop.md` are reconciled to point at that one statement, and the shadow's two structural-failure trigger lists admit an unestablished root alongside an unreadable one.
