- **The implement skill's cloud command-shape discipline now states that a bundled helper the run's own branch introduced or modified is unreachable on the cloud implement tier.** The vendored plugin checkout is version-pinned (so a just-written helper is absent — rc-127) and config grants resolve at trigger time from the default branch (so a grant the branch ships is inert — a silent denial, and a modified helper runs stale bytes at rc-0); the run recognizes such a helper from its own branch delta and routes the dependent step to the existing deferral/Blocked path up front — not only on a failed invocation, since a modified helper never fails — treating an absent, stale, or denied helper identically and attempting no workaround, rather than burning its budget on retries. `docs/internal/implement-skill.md` now points at the shipped skill body as the runtime home of this rule.
